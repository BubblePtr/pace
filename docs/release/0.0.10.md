# Pace 0.0.10

发布日期：2026-09-15

## 新功能

- Trajectory 中的 Agent 步骤可解析到子代理的真实会话；在 Inspector 中选中步骤即可打开子会话自己的时间线。
- Inspector 新增子会话控制：可停止运行中的子代理；扩展声明支持时还可向子会话发送后续消息。

## 修复

- 插件卡片不再为截断的作者、描述与来源文本弹出提示。
- Dock 栏图标提示改为在按钮左侧显示，不再遮挡相邻图标。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.10-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
