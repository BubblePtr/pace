# Pace 0.0.8

发布日期：2026-09-13

## 修复

- Add Project（+）与项目、会话的更多菜单（⋯）恢复为静态图标，悬停时不再播放动画。
- 失败的工具调用在 Trajectory 中保持单行摘要，状态与耗时不再折到第二行。
- 普通文本输入框恢复默认边框与聚焦样式；仅聊天输入框保留轻微的恒定外阴影。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.8-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
