# Pace 0.0.9

发布日期：2026-09-14

## 改进

- 重新打开历史会话时立即从本地 Journal 显示时间线，不再等待 Pi 与扩展初始化；首次发送、排队消息或切换模型时才恢复运行时。
- 每个运行中的根会话使用独立的 Pi 进程与工作目录，不同项目之间不再共享插件状态；单个会话崩溃不影响其他会话。
- pi-subagents 等后台扩展随会话内运行时运行，不再要求单独安装 Node.js 22.19 或更高版本。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.9-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
