# Pace 0.0.12

发布日期：2026-09-18

## 新功能

- 排队消息支持拖拽重排，也可以把某条排队消息直接转为对当前运行的 steer。Pi follow-up 模式为 `all` 时整批交给 agent，重排自动禁用。
- 未命名会话现在会根据首条回复自动命名，使用会话当前模型生成，无需再安装 auto-name 扩展。

## 改进

- Browser 面板打开时始终从空白状态开始，不再恢复上次的标签组。
- 浏览器加载失败时显示通俗的错误说明，并保留原始错误码。
- 渲染层增加基础 CSP，`pigui:invoke` 校验调用方，内嵌浏览器标签页无法再触发应用命令。

## 修复

- Pi 子进程被终止时遗留的未完成 run 会被结清为 interrupted，会话重新打开后不再复活成仍在运行的气泡。
- 排队消息按 Pace 消息 id 与 Pi 队列对账，被 agent 取走后可靠标记为 processing，冷加载或重试后也不会丢状态。
- Packages 页面细节打磨：Remove 改为次级按钮、空状态文案统一、安装对话框提示 git 安装可能需要一两分钟。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.12-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
