# Pace 0.0.11

发布日期：2026-09-17

## 改进

- Usage 页面重建为成本驾驶舱：可选 7 / 30 / 90 天或全部时间段，四张 KPI 卡片带迷你趋势线和环比变化，每日成本曲线、按本地时区渲染的星期 × 小时节奏热力图，以及按项目 / 模型 / 工具 / 技能的花费排行。
- 内置 Pi 运行时升级至 0.85.1。

## 修复

- 输入框中选择的模型与思考级别现在会在 Pi 创建会话时传入，首条消息即按所选模型运行。
- 已完成的子代理会话通过会话管理器解析其会话文件，实时运行时退出后仍可打开子会话时间线。
- Inspector 中的“Open child session”恢复为实心按钮样式，不再被误认为纯文本。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.11-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
