# Pace 0.0.13

发布日期：2026-09-19

## 新功能

- Settings → Providers 改为直接读取内置 Pi 运行时的 provider 列表，不再是固定的五个。Pi 0.85.1 支持的全部 40 个 provider（Radius、GitHub Copilot、Kimi For Coding、OpenRouter、Google、Groq、Mistral 等）都可以在 Pace 内以订阅或 API key 登录；以后升级 Pi 会自动带入新 provider。
- 支持登录 Earendil 的 Radius 网关：订阅走浏览器流程，也可以粘贴 API key。卡片显示 Radius 官方标。

## 改进

- 已配置的 provider 排在最前，其余按推荐顺序和字母序排列。
- 每个 provider 都有品牌标，没有图标的用首字母徽章兜底；GitHub Copilot、Kimi、OpenRouter 的底色按品牌调整。
- API Key 标签页新增过滤框，长列表可以按名称或 id 快速查找。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.13-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
